# 证据状态词表

| 状态 | 含义 |
| --- | --- |
| `observed` | 已从文件、接口、日志或界面观察到，尚未完成业务确认。 |
| `confirmed` | 有明确来源并完成了所需确认。 |
| `proposed` | 方案或建议，尚未代表已实施。 |
| `completed` | 已完成对应的实施动作，并有验证证据。 |
| `blocked` | 由于明确缺口无法继续，缺口需要被记录。 |
| `pending_confirmation` | 存在冲突或缺失，等待人确认。 |
| `unverified` | 目前只有推断、历史记录或自测，不能作为事实结论。 |
| `deprecated` | 过去有效但已被新规则或新事实替代。 |

HTTP 成功、代码测试通过、字段匹配或页面可访问，不能自动证明收款、奖励资格、生产部署、业务签字或端到端完成。
