# PRD 评审清单

- [ ] 目标用户、触发场景、问题和完成标准明确。
- [ ] 范围和非目标明确，未把后续阶段内容混入当前需求。
- [ ] 关键术语有中文含义、英文名称和来源。
- [ ] 事实、提议、假设、待确认和未验证内容已区分。
- [ ] 主流程包含输入、判断、动作、输出和异常恢复。
- [ ] 权限、状态转换、数据归属和接口边界明确。
- [ ] 验收标准包含前置条件、操作、预期结果和证据。
- [ ] 涉及计费、订单、奖励、退款或生产数据时，业务状态和技术状态没有混写。
- [ ] 运营动作、监控指标和回滚方式已说明。
- [ ] 没有凭空补全未知费率、日期、资格、接口行为或部署状态。
